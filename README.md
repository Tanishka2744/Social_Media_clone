# 📱 Social Media Clone (React)

A responsive and modern **Social Media Clone** built using **React.js**.  
This project demonstrates component-based architecture, state management, and dynamic UI rendering commonly used in real-world social media platforms.

---

## 🚀 Features

- Modern and clean user interface  
- Component-based structure using React  
- Dynamic posts layout  
- Like, comment & interaction UI (frontend only)  
- Responsive design for different screen sizes  
- Reusable components  
- Smooth navigation and UI flow  

---

## 🛠️ Tech Stack

- **React.js**
- **JavaScript (ES6+)**
- **CSS / Tailwind / Styled Components** *(as used)*
- **React Hooks**
